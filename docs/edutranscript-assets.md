## Asset gaps and selection boundaries
The site publishes a student request catalogue, issued-orders composition, mobile access and verification graphics. No distinct live registrar incoming-request queue screenshot or institution-specific production dashboard was found; communicate the documented review/approve/dispatch workflow with native editorial diagrams, not manufactured product UI. No separate API endpoint screenshot, standards dashboard or documented exchange UI was found. Existing alumni artwork is owned imagery, not a product screenshot. Do not show privacy/certification badges without corroborating scoped evidence. Do not reuse vendor-logo integration imagery or declare universal interoperability. No customer testimonials or unsupported source statistics selected. Fictional ABC University transcript artwork is not customer evidence. No passport, SSN or personal identity document is displayed.

The three unselected images were moved out of the public asset directory into `.local/reports/transcript-solution/unused-source-assets/`. Their initial inspection paths in the table are not shipping assets. The final page renders 10 images using 8 distinct local assets, with intrinsic dimensions, descriptive alt text, lazy loading below the hero and full-size source-image links.
