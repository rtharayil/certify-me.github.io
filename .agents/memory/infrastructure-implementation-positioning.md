The flagship Digital Credential Infrastructure page should explain the high-level connected university solution and discovery-led implementation for custom or integration development, always tied to the core six-layer approach.

**How to apply:** Retain the six layers when introducing systems, services or implementation stories. Explain the institution-specific solution design and agreed development scope rather than implying every source system has an existing supported connector.
