name: Shared question sections
description: One FAQ section per marketing page; preserve answer formatting when consolidating mixed sources.
---

Each marketing page should have only one “Common questions” section, rather than separate native, editorial and supporting-answer FAQ blocks.

**Why:** The user explicitly requested a single section when improving the site-wide infrastructure links, supporting resources and FAQs.

**How to apply:** Add future questions to the consolidated presentation rather than appending another FAQ section. Retain useful existing answers, question anchors and matching FAQ structured data.

Do not run previously plain-text answers through Markdown merely to unify their presentation.

**Why:** Consolidation changed straight apostrophes and stripped asterisks from repeated O*NET references, creating an unintended content change and mismatches with the published FAQ schema.

**How to apply:** Preserve each source's intended formatting. Check rendered answers against structured data, including taxonomy names and punctuation, when changing shared answer templates.
