# REVIEW AND IMPROVE THE WORKFORCE INTELLIGENCE PAGE

Review the **existing Workforce Intelligence page** in this project.

This is **ONE SINGLE B2B SOLUTION PAGE**.

Do not split it into Page 1, Page 2, Page 3, or separate products.

Do not rebuild it from scratch.

First inspect the current implementation, content, layout, components, graphics and UX. Then make targeted improvements.

---

## 1. PRODUCT POSITIONING

We provide **Workforce Intelligence for universities**.

The customer is the university.

This is a B2B product designed for university teams such as:

* Careers and Employability
* Workforce Development
* Employer Engagement
* Academic Leadership
* Faculty Leadership
* Curriculum / Skills Teams
* Strategy
* Digital Transformation
* University Leadership

The page must NOT feel like:

* A student job board
* A consumer career website
* A generic analytics dashboard
* A recruitment agency
* An AI-generated career advice tool

The page should communicate:

> **We help universities understand how their credentials and verified skills connect to the workforce.**

# 4. THE PROBLEM

Explain the university problem clearly.

Universities already have large amounts of information about:

* Programmes
* Courses
* Modules
* Credentials
* Learners
* Skills
* Graduate outcomes

But this information is often disconnected from external labour-market intelligence.

The university needs to understand:

* Which skills are employers demanding?
* Which occupations require those skills?
* Which programmes develop those skills?
* Where are skills gaps?
* Which industries are growing?
* Which employers are hiring?
* Which career pathways are connected to each programme?
* How is employer demand changing?

Make this concrete rather than using generic statements about “transformation”.
