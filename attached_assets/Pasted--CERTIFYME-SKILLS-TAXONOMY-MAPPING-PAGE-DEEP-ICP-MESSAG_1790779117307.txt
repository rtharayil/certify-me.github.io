# 1. BUSINESS POSITIONING

CertifyMe is a B2B institutional platform.

This page is NOT primarily for individual learners.

It is NOT a student-facing skill-mapping tool.

It is NOT a generic AI skill extraction product.

It is NOT simply a feature for attaching keywords to digital badges.

The solution should be positioned as an **institutional skills intelligence layer**.

It connects:

**Academic / Professional Learning**
→ **Learning Outcomes**
→ **Credentials**
→ **Skills**
→ **Skills Taxonomy**
→ **Occupations**
→ **Workforce Intelligence**

# 9. GOVERNANCE SHOULD BE A MAJOR DIFFERENTIATOR

The existing page has strong governance language.

Retain it and elevate it.

The message should be:

> Skills mapping should support institutional governance—not replace it.

Make these principles prominent:

### Institutional ownership

The institution defines what its programmes, credentials and certifications mean.

### Reviewed mappings

Mappings can be reviewed and approved by authorised academic or professional teams.

### Traceable evidence

A skill remains connected to the achievement, credential or evidence from which it is derived.

### Versioning

Mappings can evolve as programmes, standards and external frameworks change.

### Provenance

The system should distinguish institutional claims from external taxonomy relationships.

This is a significant differentiator from generic AI skill extraction.

# 18. EXPLAIN TAXONOMY VS SKILLS FRAMEWORK

Add a concise educational explanation.

The page should help a non-technical executive understand:

### What is a skills taxonomy?

A structured way of organising skills and relating them to other concepts.

### What is skills mapping?

The process of relating institutional learning outcomes, competencies or credential achievements to those structured concepts.

### Why does it matter?

It creates a common language that allows institutional learning data to connect with learner records, occupations and workforce intelligence.

This is excellent SEO and AI-search content.
